I work on OpenWrt and embedded Linux, with a focus on MediaTek Filogic hardware and router UX.

## Solbreaker

My main project is a self-hosted multiplayer tank server with native physics, a desktop launcher and a terminal interface. It supports game build `11.21.0.1235_7376187`.

- Local play, LAN hosting and connections to remote servers.
- Accounts, a garage and multiplayer rooms, with 7×7 bot battles, base capture and Supremacy.
- A Proving Ground for testing suspension, shots and special abilities.

[Repository](https://github.com/unisequence/Solbreaker) · [Latest release](https://github.com/unisequence/Solbreaker/releases/latest)
