# Unisse

I work on OpenWrt and embedded Linux, with a focus on MediaTek Filogic
hardware and router UX.

## Current work

- [Freenetic](https://github.com/unisequence/freenetic) — a clean-room
  reimplementation of Keenetic's UX and CLI on top of vanilla OpenWrt.
  It is a separate project and does not use proprietary KeeneticOS/NDM code.
- [BT-RB300 support for OpenWrt](https://github.com/openwrt/openwrt/pull/25034)
- [Tenbay WR3000K U-Boot layout variant](https://github.com/openwrt/openwrt/pull/24662)
- [Teralink TL3020 128 MiB support](https://github.com/openwrt/openwrt/pull/24694)

## OpenWrt work

- [Netis N6 V2 support](https://github.com/openwrt/openwrt/pull/24089)
- [Netis N6 V2 25.12 backport](https://github.com/openwrt/openwrt/pull/24548)

## Focus

- MediaTek Filogic board bring-up and device trees
- U-Boot, SPI-NAND/NMBM layouts, and recovery paths
- Router web interfaces and CLI tools on vanilla OpenWrt
- Testing changes on real hardware
